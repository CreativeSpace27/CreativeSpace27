### 📱 LinkUp — Parental Control App

[![GitHub](https://img.shields.io/badge/View%20Repo-%23121011.svg?style=for-the-badge&logo=github&logoColor=white)](https://github.com/CreativeSpace27/LinkUp)

</div>

> *Because "just don't use your phone" was never going to work.*

A robust Android parental control app built on a **"Backend as the Law"** philosophy — no amount of cache clearing, reinstalling, or device tricks can bypass the rules. Device states are continuously synced to a **Supabase cloud backend** as the single source of truth. Parents get a real-time dashboard to instantly grant or deny screen-time extension requests.

**✦ Key Highlights:**
- ☁️ Tamper-proof architecture — app reinstalls or cache wipes can't bypass rules
- ⚡ Real-time request-and-approval system for screen-time governance
- 🔒 Persistent discipline enforced at the cloud level, not the device level

### 🤖 Organizational Memory Engine — Multi-Agent AI System

[![GitHub](https://img.shields.io/badge/View%20Repo-%23121011.svg?style=for-the-badge&logo=github&logoColor=white)](https://github.com/CreativeSpace27/OrgMemoryEngine)

</div>

> *Give your organization a brain that never forgets.*

A multi-agent AI system that stores, retrieves, and **reasons over organizational decisions** using semantic vector search. When queried, it doesn't just retrieve — it *thinks*, using Ollama-powered LLMs to generate explainable answers with **full source attribution**, making every AI response traceable and auditable.

**✦ Key Highlights:**
- 🧠 Semantic search over historical decisions and knowledge using ChromaDB
- 💬 LLM reasoning layer via Ollama for human-like, explainable responses
- 📎 Source attribution on every answer — no black-box outputs
