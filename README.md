### 📱 LinkUp — Parental Control App
> *Because "just don't use your phone" was never going to work.*

[![GitHub](https://img.shields.io/badge/View%20Repo-121011?style=flat-square&logo=github&logoColor=white)](https://github.com/CreativeSpace27/LinkUp)

A robust Android parental control app built on a **"Backend as the Law"** philosophy — meaning no amount of cache clearing, reinstalling, or device tricks can bypass the rules. Device states are continuously synced to a Supabase cloud backend as the single source of truth. Parents get a real-time request-and-approval dashboard to instantly grant or deny screen-time extensions, keeping governance live and responsive.

`XML` `Java` `Supabase` `Real-time Sync` `Cloud Architecture`

### 🤖 Organizational Memory Engine — Multi-Agent AI System
> *Give your organization a brain that never forgets.*

[![GitHub](https://img.shields.io/badge/View%20Repo-121011?style=flat-square&logo=github&logoColor=white)](https://github.com/CreativeSpace27/OrgMemoryEngine)

A multi-agent AI system designed to store, retrieve, and reason over an organization's institutional knowledge — decisions, rationale, and context — using semantic vector search. When queried, the system doesn't just retrieve; it *reasons* using Ollama-powered LLMs and provides answers with full source attribution, making AI responses explainable and auditable.

`FastAPI` `Python` `Ollama` `ChromaDB` `Semantic Search` `Multi-Agent`
